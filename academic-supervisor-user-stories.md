# Academic Supervisor User Stories

## User Stories

1. As an academic supervisor, I want to evaluate students based on their application of knowledge in real-world settings so that I can assess their practical competence.

2. As an academic supervisor, I want to review and track student internship logs so that I can ensure progress is properly documented.

3. As an academic supervisor, I want to approve or reject submitted logbook entries so that only accurate and complete records are kept.

4. As an academic supervisor, I want to provide feedback on student performance so that students can improve.

---

## Acceptance Criteria

- Supervisor can view submitted student logbooks
- Supervisor can evaluate and grade entries
- Supervisor can approve or reject submissions
- Supervisor can leave comments/feedback
